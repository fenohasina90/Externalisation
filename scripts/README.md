# scripts/

Scripts fournis pour installer et démarrer CABEX Externalisation en mode tout-en-un (JAR).

- `linux-start.sh` — démarrage Linux (dossier d'installation contenant `backend.jar` et `.env`).
- `windows-start.ps1` — démarrage Windows PowerShell.
- `linux-cabex.service` — unité systemd pour démarrer automatiquement sous Linux.

Documentation complète : `documentation/DEPLOIEMENT-JAR.md`.
